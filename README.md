# Anhad & Toshi · Anand Karaj invite

Scroll/swipe-driven Gurdwara invitation (mobile-first).

## Edit the details
Open `index.html` and change the `INFO` block near the top of the script:
names, parents, date line, time, venue, start/end time (for the countdown and calendar),
Google Maps search text, and the WhatsApp number for confirmations (`rsvpPhone`, country code, no +).
Set `preview: false` to remove the "preview" label.

## Files
- `a/open.mp4`: card opening (loads first)
- `a/rest.mp4`: the continuous camera film (loads after the tap)
- `a/s*.webp`, `a/d*.webp`: still frame + depth map for each stop (3D camera)
- `a/*.mp3`: Ik Onkar music bed, ambiences and sound effects
- `a/f/`: fonts (self-hosted)
